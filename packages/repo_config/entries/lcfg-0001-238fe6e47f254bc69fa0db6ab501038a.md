## Lesson Learned Configuration — Standard Shape

**Shape:** a `##` heading naming the lesson, a **Date:** line, then **What happened**, **What it taught**, **What to do differently**, and a closing **Reference:** footer.

**Used here for** keeping what a failed or surprising verification taught, so the knowledge outlives the result: for example, a test criterion that was too loose, a requirement parameter that was ambiguous, or a model property that was missing. Always cite the result (and VCP) by real artifact ID.

**Reference:** `repo_config` observation configuration and decision configuration.
