## Note Configuration — Standard Shape (covers note, milestone, issue)

**Shape:** a `##` heading, a **Date:** line, the body, and a closing **Reference:** footer.

**Named subtype: Block Run Summary** (a `milestone`). Written once per block creation or block run, in package `test_results`. Title: `## Block Summary: <scope> — <created | run>`. Sections: **Scope** (model phase or subtree and model commit), **Counts** (VCPs created, skipped for no requirement, flagged for ambiguous parameter; or tests run with pass, fail, stale counts), **Flagged items** (object name and reason, by artifact ID where one exists), and **Reference** listing the VCPs or results covered.

**Issues** are used for problems with the demo itself (a tool that could not do something the agent needed). Record the operation attempted and what was missing; these feed the MCP tool-surface discussion directly.

**Reference:** `repo_config` observation configuration.
