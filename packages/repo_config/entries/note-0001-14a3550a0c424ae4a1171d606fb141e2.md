## Purpose — Test_Repo_for_VCP

This notebook exists to **demonstrate AI-assisted verification capture**: Verification Capture Points (VCPs) for model objects, the tests that verify them, and the results those tests produce, with an AI agent doing the capturing, planning, running, and re-verifying while the engineer stays the authority.

It is a **demo and teaching notebook**, not a production verification record. Its audience is VeriThreader development engineers, and its job is to make visible what an agent can do with a VCP-shaped, graph-like record when it is reachable through MCP.

**Packages in scope:**
- `vcps` — one entry per model object under verification, with its properties and requirements.
- `tests` — replayable test routines that verify VCPs.
- `test_results` — one append-only entry per test execution.
- `repo_config` — this notebook's configuration singletons.

Content that strains against this purpose (for example real customer verification data) belongs in a separate notebook.

**Reference:** `candidate_playbooks`/OBS-0020 in `knowledge_partner` (the playbook this notebook is the worked example for).
